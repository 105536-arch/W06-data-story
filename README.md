# W06｜Data Story：我的資料故事

## 一、研究問題

1. 哪一科的平均成績最高？
2. 讀書時數和數學成績有什麼關係？

我想透過圖表觀察各科成績的差異，以及讀書時數與數學成績之間的關係。

## 二、圖表一：各科平均成績

- **圖表類型：** 長條圖
- **選擇原因：** 長條圖適合比較不同科目的平均成績。
- **觀察結果：** 國文平均成績為 80.2 分，英文和數學平均都是 78.0 分。國文平均成績最高。

## 三、圖表二：讀書時數與數學成績

- **圖表類型：** 散佈圖
- **選擇原因：** 散佈圖可以觀察兩個數值變數之間的關係。
- **觀察結果：** 讀書時數與數學成績的相關係數為 0.98，顯示這份資料中的兩者有很強的正相關。

## 四、分析結論

在這份學生資料中，國文平均成績最高，英文與數學平均成績相同。此外，讀書時數與數學成績呈現很強的正相關。

不過，這份資料只有 10 位學生，而且是範例資料。相關不代表因果，因此不能直接認定讀書時間增加一定會讓數學成績提高，也不能直接推論所有學生都有相同情況。

## 五、學習心得

今天我發現，圖表不只是呈現數字，還可以幫助我們比較資料與觀察變數之間的關係。

我原本以為只要看成績就能了解學習情況，現在我知道也可以透過讀書時數和成績的圖表進一步分析。

我最滿意的圖表是讀書時數與數學成績的散佈圖，因為它讓我看出兩者在這份資料中呈現正相關。

我遇到的問題是 Python 一開始找不到資料檔，而且缺少 matplotlib 套件。我透過確認檔案位置、安裝套件和重新執行程式，最後成功產生兩張圖表。
